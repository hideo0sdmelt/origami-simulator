# 要件

このツールで何をしたいか、何をしないかをまとめる。機能の細かい動きは [spec.md](spec.md)、内部の仕組みは [architecture.md](architecture.md) を参照。

## きっかけ

謎解きをしていて、紙を折る問題がある。友達にも同じ謎解きをやらせたいので、手元の紙には折り目を付けたくない。そこで、紙の画像をデジタル上で折れるようにしたい。

## 目的

謎解きの紙を、実物に折り目を付けずに画面の上で折る。

- 紙の表と裏の画像を読み込み、その絵柄のまま折れる
- 折った結果、どの文字や絵が表に出て、どれが重なって隠れるかを確かめられる
- 何度でもやり直せる

## 想定する使い方

紙の画像は、手に入る形に合わせて用意する。

- デジタルデータ(PDF や画像)が配られている謎解きなら、それを画像にして使う
- 手元の紙しかないなら、スマホで写真を撮る(アプリの中で紙の部分を切り抜ける)か、Google ドライブのスキャン機能などでスキャンする

用意した画像を、パソコンかスマホで開いて折ってみる。1人で使う道具で、アカウントやデータの共有はない。

## 要件

### 折る

- 折り線を自由に引いて折れる
- 「この角をこの点に合わせる」「この辺をこの辺に合わせる」折り方ができる(実物の折り紙でよくやる折り方)
- 谷折り・山折りを選べる
- 紙全体を裏返したり、90°回したりできる
- 戻す・進むができる。どの折りが戻ったか分かるよう、アニメーションで見せる

### 切る(2026-11-14 追加)

- 謎解きでは「折ったあと、ここを切れ」と言われることがある。折った状態のまま、重なった紙をまとめて直線で切れるようにする
- 切ったあとの使い方は3通りあるので、全部できるようにする
  - 切り落とした側は捨てて、そのまま続ける
  - 残した側を広げて、切った形を見る
  - 切り落とした側を広げて見る
- 「切ったら、どちらを残すか選ぶ」1つの操作にまとめ、反対側への入れ替えと、切ったまま広げる操作を足す
- 切る線は直線だけ。曲線は扱いが難しいわりに使う場面が少ないのでやらない。穴あけもやらない。折れ線は、直線で使ってみて必要になったら考える
- 折り紙シミュレーターの中に入れる(別のアプリにしない)。切るには、どの面がどこに何枚重なっているかが要り、それを持っているのはこのアプリだけのため

### 紙の画像

- 表と裏の画像を、選ぶ・ドロップ・貼り付けで読み込める。スマホではその場で撮れる
- 画像ごとに90°ずつ回して向きを合わせられる
- 裏の画像の撮り方(左右にめくった/上下にめくった)の違いを吸収できる
- 画像を入れなくても、サンプルの紙で試せる

### 写真から紙を切り抜く(2026-11-23 追加)

- 普通に撮った写真には、背景や傾きが入る。読み込んだ写真から紙の部分だけを切り抜き、斜めから撮っても真上から見た形に直す。4つの角を指で合わせる
- 謎解きの紙は正方形とは限らない(長方形・短冊・はがきなど)。切り抜いた紙の縦横比は、写真から推定する。推定がずれることもあるので、もう片方の面に合わせる・正方形・A判・はがきからも選べる
- 表と裏を同じ縦横比にして、裏を引き伸ばさずに重ねられるようにする
- 切り抜く形は四角だけ。変わった形の紙は、四角で切り抜いてから「切る」で形を作る
- デジタルデータやスキャンした画像は、切り抜かずにそのまま使える
- アプリの中に入れる(別のカメラアプリや、Google ドライブのスキャンは使わない)。読み込みのすぐ後に挟めて、表と裏の縦横比を揃えられるのはこのアプリだけのため
- 角の自動検出は、まずはやらない。手で合わせて使ってみて、手間なら考える

### 見やすさ

- 重なった下の層を透かして見られる。透かす濃さを変えられる
- 押した場所に重なっている紙を、上から順に1枚ずつ見られる。「〇〇の下にある文字を読め」「シャーペンで貫け」のような問題に使う
- 角・辺の中点・辺に吸い付く(スナップ)ので、狙った位置で折れる

### スマホ対応(2026-11-13 追加)

- URL はそのままで、スマホのブラウザでも使いやすくする
  - 作業台を画面いっぱいに使う。画像の読み込みや設定は、必要なときだけ開く
  - ボタンは指で押しやすい大きさにする
  - 2本指で拡大・移動できる(小さい画面でも細かく折れるように)
  - 指で隠れる場所を拡大鏡で見せる
- ホーム画面に追加して、アプリのように使える(PWA)。一度開けば電波がなくても使える
- ストアに出すネイティブアプリにはしない。審査や費用のわりに得るものがないため
- 今どきのスマホ(幅360px以上)を主な対象にする。横向きでも使える。それより狭い古い機種は、崩れない程度に対応する

### 続きから再開する(2026-11-14 追加)

- 画像、折った状態、戻す・進むの履歴、設定を自動で保存し、次に開いたときに続きから再開する。スマホがアプリを切り替えた間にページを閉じても、作業が消えないようにする
- 使い方は「謎解きの最中にその場で折って、終わったら終わり」。次の謎解きで前の紙が出てこないよう、最後に触ってから12時間を過ぎた保存は使わず、まっさらで始める
- 保存は1つだけ(いまの状態)。複数の作業を名前を付けて残す機能は持たない

### プライバシー

- 画像はブラウザの中だけで扱い(保存もブラウザの中)、どこにも送らない
- サーバーを持たない。GitHub Pages の静的ページだけで動く

## やらないこと

- 立体的な表示(3D)。紙は常に平らに重ねて表示する
- 開く、差し込むなどの、折る・切る以外の操作
- 曲線で切る、穴をあける
- 折り図や手順の書き出し
- ログインや、データのクラウド保存・共有

## 今後の候補

優先度順ではない。

- 写真の中の紙の角を自動で見つけて、切り抜く範囲の初期位置にする(いまは画像の四隅から始めて、手で合わせる)
- 折れ線で切る。直線で使ってみて、足りない場面が出てきたら考える
- iPhone の実機での確認(手元にないため、WebKit での確認までしかしていない)
