# 機能仕様

画面の構成と、各機能の動きをまとめる。なぜそうするかは [requirements.md](requirements.md)、どう実装しているかは [architecture.md](architecture.md) を参照。

## 画面の構成

| 部分 | 中身 |
|---|---|
| ヘッダー | タイトル、手順数と面の数(`手順 3 · 面 6`)、スマホでは「紙と設定」ボタン。手順数は、いまの紙を何回折ったか(「広げて最初から」のあとは0から数える) |
| 作業台 | 紙を置く緑のマット。上に道具の切り替えと説明文、下にボタン列 |
| パネル | 紙の画像、裏の撮り方、表示の設定、使い方、アプリとして使う、広げて最初から |

### 画面の幅・高さによる切り替え

| 条件 | 配置 |
|---|---|
| 幅 821px 以上かつ高さ 521px 以上(パソコン) | 作業台の右に幅300pxのパネルを常に表示 |
| 幅 820px 以下、または高さ 520px 以下(スマホ) | 作業台が画面いっぱい。パネルは「紙と設定」で下から出るシートになる。ボタンは高さ44px以上。戻す・進む・90°はアイコンだけ |
| 高さ 520px 以下(横向きのスマホ) | 上に加えて、タイトル行を隠し、「紙と設定」を作業台の右上に重ねる。説明文は道具の切り替えの横に並べる |
| 幅 380px 以下 | 手順数の表示を隠す |
| 幅 359px 以下 | 道具の切り替えとボタン列の余白・文字を詰め、1段に収める |

シートは、背景の暗い部分か「閉じる」を押すか、Esc で閉じる。

## 紙

- 表と裏の画像を、枠をタップ/クリックして選ぶ、ドロップする、貼り付ける(Ctrl+V)で読み込む
  - 貼り付けと、枠以外(作業台など)へのドロップは、表が空なら表、表があって裏が空なら裏、両方あれば表に入る
  - ページのどこにドロップしても、ブラウザが画像を開いてページから離れることはない
  - スマホでは、枠をタップするとカメラで撮ることもできる
- 読み込むと、写真の中の紙を探す。見つかったら「紙の部分を合わせる」画面が開く(下の「写真から紙を切り抜く」)。見つからなければ(スキャンや PDF のように、画像全体が紙のとき)そのまま使い、「表を読み込みました(紙の部分を切り抜くときは「表を切り抜く」)」と3.5秒出す
- 紙として使う画像は、長い辺が1600pxまで。切り抜く前の写真は、長い辺2400pxに縮めてメモリに残す(切り抜き直すため)。元の大きさの画像はメモリに残さない
- 紙の大きさは表の画像に合わせる(表がなければ裏)。裏の縦横比が表と3%以上違うときは、裏を表の形に伸ばし、パネルに注意を出す
- 片方しかないときは、もう片方を白紙として扱う
- 「表を回転」「裏を回転」で、画像ごとに時計回りに90°回す
- 「表と裏を入れ替え」「サンプルに戻す」ができる
- 画像の読み込み・回転・入れ替え・サンプルに戻すで、紙の大きさ(縦横のpx)が変わらなければ、折った状態と履歴を保ち、絵柄だけを差し替える
- 紙の大きさが変わるときは、折った状態と履歴をリセットする。折りや履歴があるときは、先に確認を出し、やめることもできる
- 折りのアニメーション中に画像の読み込みが終わったときは、アニメーションが終わってから差し替える
- 画像がないときは、サンプルの紙(表に「なぞときをたのしもう」、裏に1〜9の数字を書いた3×3のマス)を使う

### 写真から紙を切り抜く

画像を読み込んで(選ぶ・撮る・ドロップ・貼り付けのどれでも)紙が見つかったときと、パネルの「表を切り抜く」「裏を切り抜く」を押したときに、画面いっぱいに「表(裏)の紙の部分を合わせる」画面を開く。

- 画像の上に、切り抜く範囲の4つの角を丸で出す。最初は見つけた紙の角にある(見つからなかった画像を切り抜くときは、画像の四隅)。外側は暗くする
- 丸をドラッグして、紙の角に合わせる。丸は指の動きに合わせて動く(指の下に飛んでこない)ので、指で隠れない。タッチでは、動かしている角を3倍に拡大した円を指の上に出す
- 丸をつかめる距離は、マウス18px、タッチ44px。画像の外には出せない
- 角はどの順に並べてもよい。切り抜くときに、左上・右上・右下・左下に並べ直す
- 縦横比(プルダウン)
  - もう片方の面に合わせる(もう片方の画像があるとき。既定):もう片方と同じ縦横の大きさで切り抜く。裏を引き伸ばさずに重なる
  - 写真から推定(もう片方がないときの既定):合わせた4つの角から、紙の縦横比を計算する。項目名に、いまの推定(`縦長 1:1.41` など)を出し、角を動かすたびに変わる
  - 正方形 / A判・B判(1:1.41)/ はがき(1:1.48):縦長か横長かは、推定に合わせる
- もう片方の面に画像があるときは、「表を重ねる」(裏を重ねる)のスライダーを出す。もう片方の面を、紙をめくったときの向き(裏の画像の撮り方に従って左右か上下に反転)で、4つの角の中に半透明で重ねる。チェックボックスで重ねる・重ねないを切り替えられる(既定は重ねる。開き直しても前の選択のまま)。濃さは10〜90%(既定40%)。両面に見える折り線や透けた印が重なるように角を動かすと、もう片方と同じ範囲で切り抜ける。拡大鏡の中にも重ねる
- 切り抜いた画像の大きさは、写真の中の紙の大きさ(px)くらいで、長い辺1600pxまで
- ボタン
  - 切り抜いて使う(Enter):真上から見た長方形に直して、紙の画像にする。4つの角が近すぎるときは「4つの角が近すぎます。紙の角に合わせてください」と出す
  - 切り抜かずに使う:写真をそのまま紙の画像にする(デジタルデータやスキャン向け)
  - やめる(Esc、ブラウザの「戻る」):読み込みをやめる。切り抜き直しのときは、いまの画像のまま
- 使うと「表を読み込みました」(切り抜き直しのときは「表を切り抜き直しました」)と出す。紙の大きさが変わるときの確認は、ほかの画像の差し替えと同じ
- パネルの「表を切り抜く」「裏を切り抜く」で、切り抜き直せる。前に合わせた角の位置から始まる
  - 自動で使った画像(紙が見つからなかった)を切り抜くときは、もう一度紙を探し、見つからなければ画像の四隅から始まる
  - 切り抜く前の写真は保存しない。再読み込みしたあとは、いま使っている画像から切り抜く
  - 画像の90°回転は、切り抜き直しても保つ
- この画面が開いている間は、ほかの画像の読み込み(貼り付け・ドロップ)とキー操作を受け付けない

### 裏の画像の撮り方

裏の画像は、紙をめくって撮ったものとして扱う。めくり方によって、表と重ねるときの反転の向きが変わる。

- 紙を左右にめくって撮った(既定):左右を反転して重ねる
- 紙を上下にめくって撮った:上下を反転して重ねる

表と裏の絵柄がずれて重なるときは、ここを切り替える。

## 折り方の指定(3種類)と重なりを見る・切る

作業台の上の切り替えで選ぶ。スマホでは1段に収めるため、短い名前(線を引く・点合わせ・辺合わせ・重なり・切る)にする。

### 折り線を引く

1. 紙の上をドラッグして折り線を引く。12px未満の短い線は取り消す
2. 線の両端の●をドラッグして位置を調整できる
3. 折りたい側を選んで折る
   - マウス:カーソルがある側が黄色く表示され、クリックで折る
   - タッチ:タップで側を選び、同じ側をもう一度タップで折る。反対側をタップすると選び直す
   - 線のすぐ近く(マウス3px、タッチ8px以内)では、どちら側か決められないので折らない。押すと「線から少し離れて、折りたい側をクリック(タップ)してください」と出す
4. 「線を消す」かEscで取り消す

### 点を合わせる

動かしたい点(角など)から、重ねたい点へドラッグする。2点を結ぶ線の垂直二等分線が折り線になり、動かす側は最初の点がある側に決まる。離すと「谷折りで折る」(山折りのときは「山折りで折る」)ボタンが出る。紙の上をタップかクリックしても折れる。紙の外をタップかクリックすると取り消す(辺を合わせるも同じ)。

### 辺を合わせる

動かしたい辺の近くから、重ねたい辺へドラッグする。2本の辺が重なる折り線(角の二等分線。平行なら中間の線)を求める。2本の二等分線のうち、動かす辺の中点がもう一方の辺に近く重なる方を選ぶ。辺の近くから始めなかったときは、指を離したときに「紙の辺の近くからドラッグしてください」と出す。

例:長方形の上の辺を右の辺へドラッグすると、先端に三角ができる。

### 重なりを見る

1. 切り替えで「重なり」を選ぶ
2. 紙の上をタップ/クリックすると、その場所に重なっている紙を、作業台の下(ボタン列の上)に上から順に並べる。紙の上の見ている場所には赤い十字の印を出す
3. 1枚ごとに、その層だけを描いた小さな絵(画面で約140px四方の範囲)と、何枚目か、表か裏かを出す。絵の中心の赤い丸が見ている場所
4. ドラッグすると、見る場所が動き、並びもそのつど変わる。タッチでは拡大鏡も出す
5. 紙の外をタップ/クリックするか、「×」で閉じる。ほかの道具に切り替えたときや、折る・戻す・裏返すなどで紙が変わったときも閉じる

### 切る

1. 切り替えで「切る」を選ぶ
2. 紙の上をドラッグして切る線を引く。引き方は「折り線を引く」と同じ(12px未満は取り消す、端の●で調整、スナップと角度の吸い付き、拡大鏡)。線は実線で描き、横に「切る」の札を出す
3. 残したい側を選んで切る。切り落とす側は暗く表示する
   - マウス:カーソルがある側が残る側になり、クリックで切る
   - タッチ:タップで残す側を選び、同じ側をもう一度タップで切る。反対側をタップすると選び直す
4. 線は紙の全部の層を貫く。切り落とした側は、線から離れながら消える(420ms)
5. 「線を消す」かEscで取り消す

- 選んだ側に紙がないときは「その側には紙がありません」、線が紙にかかっていないときは「線が紙にかかっていません」と出す
- 線は直線だけ。折れ線・曲線・穴あけはない
- 切ったあとは、手順が1つ増える。戻す・進むで、切る前と後を行き来できる

#### 反対側を残す

- 切った直後に、作業台の下に「反対側を残す」ボタンを出す
- 押すと、同じ線のまま、切り落とした側を残し、残していた側を切り落とす(700ms)。手順は増えず、直前の切りを置き換える
- 続けて押すと、また入れ替わる。消える条件は「谷折り・山折りの折り直し」と同じ

#### 切ったまま広げる

- 切ったあと、紙が折られている間は「切ったまま広げる」ボタンを出す
- 押すと、残っている紙を、元の紙の上の位置に戻して広げる(480ms、前の状態と入れ替わるように見せる)。表が上になる(裏返しや回転はいまの向きのまま)
- 折り目は、面の境目の線として見える
- 広げたあとは手順数が0に戻る(「広げて最初から」と同じ数え方)。履歴には残るので、戻すで折って切った状態に戻れる
- 広げたあとも、続けて折ったり切ったりできる
- 「広げて最初から」は、切った部分も元に戻した、まっさらな紙にする

### 谷折り・山折り

- 谷折り:動かす側を手前に折り、いまある紙の上に重ねる
- 山折り:動かす側を向こう側に折り、いまある紙の下に回す
- 折り線は折り図の記号に合わせて、谷折りなら破線、山折りなら一点鎖線で描く。折る側を選ぶ段階では、線の横に「谷折り」「山折り」の札を出し、説明文にもどちらで折るかを出す。途中で切り替えると、すぐに表示も変わる

### 共通

- 折り線は紙の全部の層を貫く。線で分かれた全部の面のうち、選んだ側にあるものがまとめて動く
- 選んだ側に紙がないときは「その側には紙がありません」と出す

## スナップ

「角・辺の中点・辺にスナップ」がオンのとき(既定でオン)、折り線の端や点を合わせる位置が次に吸い付く。優先順は、角 → 辺の中点 → 辺の上の一番近い点。

| | マウス | タッチ |
|---|---|---|
| 角・中点に吸い付く距離 | 12px | 20px |
| 辺に吸い付く距離 | 7px | 12px |
| 辺を選べる距離(辺を合わせる) | 10px | 22px |
| 線の端の●をつかめる距離 | 12px | 22px |

吸い付いた位置には黄色い丸を出す。

### 折り線の角度(折り線を引く)

- 「角・辺の中点・辺にスナップ」がオンのとき、折り線が画面の上で水平・垂直・45°から少しずれているだけ(マウス3°、タッチ5°以内)なら、その角度に揃える。線の端が角や中点に吸い付いたときは、そちらを優先する
- パソコンでは、Shift を押しながら引くと、スナップの設定に関係なく、一番近い水平・垂直・45°に必ず揃える
- 揃えるときは、動かしている端を、反対の端からその角度の向きに沿って動かす。線の端の●を動かして直すときも同じ
- 揃えている間は、線の端の近くに「水平」「垂直」「45°」の札を出す
- 画面の上で24px より短い線は揃えない(向きが定まらないため)

## 紙全体の操作

- 裏返す:紙全体を左右に裏返す(アニメーション560ms)
- ⟳ 90°:紙全体を時計回りに90°回す(380ms)
- 裏返しと回転は、戻す・進むの対象にしない。戻す・進むは折りだけを扱い、いまの向きを保ったまま折りを戻したり進めたりする

## 戻す・進む

- 戻す:Ctrl+Z(Mac は ⌘Z)か Backspace。進む:Ctrl+Y か Ctrl+Shift+Z
- ブラウザの「戻る」(マウスの戻るボタン、Android の戻る操作、Safari の戻るスワイプ)でも1手戻す
  - 紙の部分を合わせる画面が開いていれば、やめる。シートが開いていれば閉じる。重なりを表示していれば閉じる。線を引いていれば取り消す。どれでもなければ折りを1手戻す
  - 戻せる折りがないときは、ふつうにページを離れる
  - ホーム画面から開いた iPhone には戻るスワイプがないので使えない
- 折りを戻すときは、折った動きを逆再生する(460ms)。進むときは折る動きを再生する(520ms)
- 「広げて最初から」は紙を広げるが、その前の状態は履歴に残るので「戻す」で戻れる
- 新しく折ると、進む履歴は消える

### 谷折り・山折りの折り直し

- 折った直後に、作業台の下に「山折りに折り直す」(谷折りで折ったとき)か「谷折りに折り直す」(山折りで折ったとき)のボタンを出す
- 押すと、同じ折り線・同じ側のまま、谷折りと山折りを入れ替えて折り直す。いったん広げてから折り直すアニメーションを見せる(820ms)
- 手順は増えない。直前の折りを置き換えるので、戻す・進むでも折り直したほうが再生される
- 続けて押すと、また入れ替わる
- 次の操作(線を引く、戻す・進む、裏返す、回す、道具の切り替えなど)を始めたら、ボタンは消える。拡大・移動では消えない
- 谷折り・山折りの切り替え(ボタン列)は変えない
- 画像の入れ替えなどで紙の大きさが変わってリセットすると、履歴も消える(先に確認を出す)

## 表示

- 紙は、上の道具と説明文、下のボタン列を避けた範囲に収まるよう自動で拡大・縮小し、中央に置く
- 透かして見る:各層を半透明で描き、下の層がうっすら見える。オンのときは「濃さ」のスライダーを出し、20〜90%(既定60%)で変えられる
- 折った紙を画面いっぱいに拡大:折って小さくなった紙を、元の紙の6倍まで拡大して表示する
- 折る・戻す・回すなどのたびに、表示を自動で合わせ直す(アニメーション付き)
- 「動きを減らす」設定(prefers-reduced-motion)の端末ではアニメーションを省く
- 色はライト・ダークの両方に対応する(端末の設定に従う)

## 拡大・移動

- スマホ:2本指で拡大・縮小と移動を同時にする。2本目の指が触れたら、1本目で始めた操作(線を引くなど)は取り消す
- パソコン:
  - マウスのホイールで、カーソルの位置を中心に拡大・縮小する
  - トラックパッドは、2本指のスクロールで移動、ピンチ(と Ctrl+ホイール)で拡大・縮小する。トラックパッドかどうかは、Chrome/Safari の `wheelDeltaY` で見分ける。見分けられないブラウザでは、マウスと同じく拡大・縮小になる
  - 横スクロール(Shift+ホイール、チルト)で左右に移動する
  - Space を押しながらドラッグ、または中ボタンでドラッグで移動する。線を引いた途中でも使え、線は消えない。Space は、何もフォーカスしていないときか、カーソルが作業台の上にあるときだけ受け付ける(ボタンにフォーカスがあるときに Space でボタンを押せなくならないように)
- 拡大できる範囲は、自動で合わせた大きさの0.5〜12倍
- 手で拡大・移動している間は「全体を表示」ボタンが出る。押すと自動の表示に戻る(300ms)
- 手で拡大した表示は、画面の回転などで大きさが変わっても保つ。折る・戻すなどをすると自動の表示に戻る

## 拡大鏡(タッチ操作のとき)

線を引いている間、点や辺を合わせている間、線の端の●を動かしている間に出す。

- 指の位置を2.5倍に拡大し、半径40〜60pxの円に表示する
- 円は指の上に出す。画面の上端に近いときは、指の横に出す
- 中心に十字を出す。スナップした位置もそのまま見える

## 説明文

作業台の上に、いまの状態でやることを1行で出す。マウスかタッチかで言い回しを変える(例:「クリックで折る」/「タップで折る」)。タッチ端末では、最初からタッチ向けの言い回しにする。

## 続きから再開する

- 画像(縮めたもの)、折った状態、紙の向き、戻す・進むの履歴、谷折り/山折り、裏の撮り方、表示の設定を、ブラウザの中(IndexedDB)に自動で保存する
- 保存するのは、変更してから0.2秒後と、ページが隠れたとき(スマホでアプリを切り替えたときなど)
- 開いたときに保存があれば、その状態に戻し、「前回の続きから再開しました」と出す。表示の拡大・移動は戻さず、全体を表示する
- 最後の保存から12時間を過ぎていたら、戻さずにサンプルの紙で始める(前の謎解きの紙が出てこないように)。古い保存は、すぐ次の保存で上書きされる
- 復元が終わる前に操作を始めていたら、復元はせず、その操作を優先する
- 保存は1つだけ。「サンプルに戻す」をすると、サンプルの紙が保存される
- 変更してから0.2秒以内にページを再読み込みしたり閉じたりすると、その変更は保存されないことがある
- 保存できないブラウザ(プライベートモードの一部など)では、保存しないだけで、ほかの機能はそのまま使える

## アプリとして使う(PWA)

- ホーム画面に追加すると、アドレスバーなしの全画面で開く。名前は「おりがみ」
- 一度開いておけば、電波がなくても開ける
- パネルの「アプリとして使う」に追加の手順を出す
  - iPhone/iPad:Safari の共有ボタンから「ホーム画面に追加」
  - そのほか:ブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」
  - Chrome などでインストールできるときは「ホーム画面に追加」ボタンを出す
- ホーム画面から開いているときは、この項目を出さない

## キーボード

| キー | 動き |
|---|---|
| Ctrl+Z / ⌘Z、Backspace | 戻す |
| Ctrl+Y、Ctrl+Shift+Z | 進む |
| Esc | 引いた線を取り消す。シートが開いていれば閉じる。紙の部分を合わせる画面では、やめる |
| Space(押している間) | ドラッグで画面を移動する |
| 1 / 2 / 3 / 4 / 5 | 折り線を引く / 点を合わせる / 辺を合わせる / 重なり / 切る |
| V / M | 谷折り / 山折り |
| F | 裏返す |
| R | 90°回す |
| Enter | 折る(「谷折りで折る」ボタンが出ているとき。ボタンにフォーカスがあるときは、そのボタンを押す) |
| 0 | 全体を表示(拡大・移動しているとき) |
| Shift(線を引いている間) | 水平・垂直・45°に揃える |

入力欄(ファイル選択、プルダウン)にフォーカスがあるときは、キー操作を受け付けない。

## メッセージ(トースト)

作業台の上に1.8秒だけ出す。

- 「表を読み込みました」「裏を読み込みました」
- 「表を読み込みました(紙の部分を切り抜くときは「表を切り抜く」)」(裏も同じ。紙が見つからず、そのまま使ったとき。3.5秒)
- 「画像ファイルを選んでください」
- 「この画像は読み込めませんでした。PNG か JPEG で試してください」
- 「先に表の画像を入れてください」「先に裏の画像を入れてください」(画像なしで回転したとき)
- 「先に画像を入れてください」(画像なしで入れ替えたとき)
- 「表を切り抜き直しました」「裏を切り抜き直しました」
- 「4つの角が近すぎます。紙の角に合わせてください」
- 「その側には紙がありません」
- 「線が紙にかかっていません」(切るとき)
- 「紙の辺の近くからドラッグしてください」
- 「線から少し離れて、折りたい側をクリックしてください」(タッチでは「タップ」。切るときは「残したい側」)
- 「広げました(「戻す」で折った状態に戻れます)」
- 「前回の続きから再開しました」
