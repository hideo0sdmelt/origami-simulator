# おりがみシミュレーター

紙の表と裏の画像を読み込んで、画面の上で折り紙を折れるツールです。謎解きの紙などを、実物に折り目を付けずに試せます。

**使う:** https://hideo0sdmelt.github.io/origami-simulator/

## できること

- 表と裏の画像を読み込む(選ぶ・ドロップ・貼り付け)。画像ごとに90°ずつ回転できる
- 折り方は3通り
  - 折り線を引く
  - 点を合わせる(角などを別の点に重ねる)
  - 辺を合わせる(辺を別の辺に重ねる。長方形の先端に三角を作る折りなど)
- 谷折り・山折り、紙全体の裏返し・90°回転
- 戻す・進む(折った手順だけが対象。アニメーション付き)
- 透かし表示(下に重なった層をうっすら表示)
- 拡大・移動(スマホは2本指、パソコンはホイール)

画像はブラウザの中だけで扱い、どこにも送りません。

## スマホで使う

同じ URL をスマホのブラウザで開けば、そのまま使えます。

- 作業台が画面いっぱいに広がり、画像の読み込みや設定は「紙と設定」ボタンから開きます
- ドラッグ中は、指の下を拡大鏡で表示します
- ホーム画面に追加すると、アプリのように全画面で開けます。一度開いておけば、電波がなくても使えます
  - Android(Chrome):メニュー →「アプリをインストール」
  - iPhone(Safari):共有ボタン →「ホーム画面に追加」

## 仕組み

`index.html` 1枚の静的ページです。ビルドは不要で、GitHub Pages から配信しています。

ホーム画面への追加とオフライン動作(PWA)のために、次のファイルを置いています。

- `manifest.webmanifest`:アプリの名前とアイコン
- `sw.js`:オフライン用のキャッシュ。ページ本体は毎回ネットから取りにいくので、更新はすぐに反映されます。アイコンなどを差し替えたときは、`sw.js` の `VERSION` を上げてください
- `icons/`:アイコン画像
