# おりがみシミュレーター

紙の表と裏の画像を読み込んで、画面の上で折り紙を折れるツールです。謎解きの紙などを、実物に折り目を付けずに試せます。

**使う:** https://hideo0sdmelt.github.io/origami-simulator/

- 折り線を引く・点を合わせる・辺を合わせるの3通りで折れる。谷折り・山折り、戻す・進むもできる
- 撮った写真から紙の部分を切り抜ける。4つの角を合わせると、斜めから撮っても真上から見た形に直す。縦横比は写真から推定するか、表裏・正方形・A判・はがきから選ぶ
- 折った紙を直線でまとめて切れる。残す側を選び、切ったまま広げて形を確かめられる
- パソコンでもスマホでも使える。ホーム画面に追加すると、アプリのように全画面で開ける
- 途中で閉じても、次に開くと続きから再開できる
- 画像はブラウザの中だけで扱い(保存もブラウザの中)、どこにも送らない

## 開発

`index.html` 1枚の静的ページで、ビルドは不要です。`main` に push すると GitHub Pages に反映されます(リリース作業はなし)。アイコンや manifest を変えたときは `sw.js` の `VERSION` を上げます。詳しくは [仕組み](docs/architecture.md#公開と更新) を参照。

ローカルで確認するとき:

```sh
python -m http.server 8000
# http://localhost:8000/ を開く
```
