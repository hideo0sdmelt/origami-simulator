# おりがみシミュレーター

紙の表と裏の画像を読み込んで、画面の上で折り紙を折れるツールです。謎解きの紙などを、実物に折り目を付けずに試せます。

**使う:** https://hideo0sdmelt.github.io/origami-simulator/

## できること

- 表と裏の画像を読み込む(選ぶ・ドロップ・貼り付け)。画像ごとに90°ずつ回転できる
- 折り方は3通り
  - 折り線を引く
  - 点を合わせる(角などを別の点に重ねる)
  - 辺を合わせる(辺を別の辺に重ねる。長方形の先端に三角を作る折りなど)
- 谷折り・山折り、紙全体の裏返し・90°回転
- 戻す・進む(折った手順だけが対象。アニメーション付き)
- 透かし表示(下に重なった層をうっすら表示)

画像はブラウザの中だけで扱い、どこにも送りません。

## 仕組み

`index.html` 1枚だけの静的ページです。ビルドは不要で、GitHub Pages から配信しています。
